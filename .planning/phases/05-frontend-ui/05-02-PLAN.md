    Create a hook using `useQuery`. Fetches `GET /api/communities/${communityId}/stances`. Returns `{ data: Stance[] }`.

    CRITICAL: This hook MUST shuffle the stances array before returning. The `position` field (1-5) must NEVER be exposed to any rendering code. Implement Fisher-Yates shuffle:

    ```typescript
    function shuffle<T>(arr: T[]): T[] {
      const a = [...arr]
      for (let i = a.length - 1; i > 0; i--) {
        const j = Math.floor(Math.random() * (i + 1))
        ;[a[i], a[j]] = [a[j], a[i]]
      }
      return a
    }
    ```

    - queryKey: `['stances', communityId]`
    - queryFn: Fetch, then shuffle the data array before returning. Strip the `position` field entirely from each stance object — return only `{ text, supportingPoints, description, examplePerspectives }` (create a `DisplayStance` type that omits `position`).
    - `staleTime: 30 * 60_000` (30 minutes — stances are static content)
    - `enabled: !!communityId`
    - Export both the `DisplayStance` type and the hook.

    The returned data from useStances must have the `position` field removed. Create a `DisplayStance` type:
    ```typescript
    export type DisplayStance = Omit<Stance, 'position'>
    ```

    All three hooks import `apiFetch` from `'../lib/apiFetch'` and types from `'../types'`.
