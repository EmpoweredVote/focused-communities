## Decisions Made

- **Tailwind v4, no config file:** `@tailwindcss/vite` plugin handles everything; `tailwind.config.js` not needed and would conflict with v4
- **VITE_API_BASE_URL defaults to empty string:** In dev, relative `/api/*` paths route through Vite proxy; in production set env var to absolute backend URL
- **vite-env.d.ts not created:** Vite 9 template no longer generates this file; covered by `"types": ["vite/client"]` in tsconfig.app.json
- **App.tsx written fresh:** The scaffolded template content referenced deleted assets (`App.css`, `assets/` directory) and couldn't build — replaced entirely with route tree
