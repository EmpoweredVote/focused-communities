    **useThreads (frontend/src/hooks/useThreads.ts):**
    Create a hook using `useInfiniteQuery`. Fetches `GET /api/communities/${communityId}/threads` with `sort` and `cursor` params.

    - Parameters: `(communityId: string | undefined, sort: 'active' | 'newest' = 'active')`
    - queryKey: `['threads', communityId, sort]` — sort is in the key so switching sort refetches
    - queryFn: Build URL with `?sort=${sort}` and optional `&cursor=${pageParam}`. Use `apiFetch<PaginatedResponse<ThreadSummary>>`. If `!result.ok`, throw.
    - `initialPageParam: null as string | null` (REQUIRED for v5)
    - `getNextPageParam`: `lastPage.meta.hasMore ? lastPage.meta.cursor : undefined`
    - `refetchInterval: 30_000` — 30s polling to pick up new threads/activity
    - `refetchIntervalInBackground: false` — stop polling when tab is hidden
    - `enabled: !!communityId`
    - Export convenience: `const threads = data?.pages.flatMap(p => p.data) ?? []`

    **useThread (frontend/src/hooks/useThread.ts):**
    Create a hook using `useQuery`. Fetches `GET /api/threads/${threadId}`. Returns `{ data: Thread }`.

    - Parameters: `(threadId: string | undefined)`
    - queryKey: `['thread', threadId]`
    - queryFn: Use `apiFetch<{ data: Thread }>`. If `!result.ok`, throw.
    - `enabled: !!threadId`
    - `staleTime: 30_000` (30s — same as thread list cache)

    **usePosts (frontend/src/hooks/usePosts.ts):**
    Create a hook using `useQuery`. Fetches `GET /api/threads/${threadId}/posts`. Returns `{ data: Post[] }`.

    - Parameters: `(threadId: string | undefined)`
    - queryKey: `['posts', threadId]`
    - queryFn: Use `apiFetch<{ data: Post[] }>`. If `!result.ok`, throw.
    - `enabled: !!threadId`
    - `refetchInterval: 30_000` — poll for new replies
    - `refetchIntervalInBackground: false`

    All hooks import types from `'../types'` and `apiFetch` from `'../lib/apiFetch'`.
