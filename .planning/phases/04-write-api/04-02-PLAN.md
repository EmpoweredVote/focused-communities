    **PATCH /api/threads/:id** — Add to `src/routes/threads.ts`:

    Import `cacheDel` from `../lib/redis.js` (if not already imported from 04-01).

    1. Add route: `threadsRouter.patch('/threads/:id', requireAuth, requireConnected, async (req, res) => { ... })`
    2. Extract `title` and `body` from `req.body`. At least one must be present:
       - If both are `undefined`: return `422` with `{ errors: { _: 'At least one of title or body is required' } }`
    3. Validate only the fields that are present:
       - If `title !== undefined`: `const trimmedTitle = title.trim()` — if length < 5 or > 150: add to errors
       - If `body !== undefined`: `const trimmedBody = body.trim()` — if length < 10 or > 5000: add to errors
       - If errors: return `422` with `{ errors }`
    4. Ownership check — fetch existing thread (service role bypasses RLS, so we MUST check manually):
       ```typescript
       const { data: existing, error: fetchError } = await supabase
         .schema('connect')
         .from('threads')
         .select('id, author_id, moderation_status, title, body')
         .eq('id', req.params.id)
         .single();
       ```
       - If `fetchError || !existing || existing.author_id !== req.user!.id || existing.moderation_status !== 'visible'`: return `404` with `{ error: { code: 'THREAD_NOT_FOUND', message: 'Thread not found' } }`
       - CRITICAL: Return 404 (not 403) when non-author — hides existence of content. This matches Phase 3's approach for moderated content.
    5. Build update object — only include fields that were provided:
       ```typescript
       const updates: Record<string, string> = {};
       if (title !== undefined) updates.title = trimmedTitle;
       if (body !== undefined) updates.body = trimmedBody;
       updates.updated_at = new Date().toISOString();
       ```
    6. Execute update:
       ```typescript
       const { data, error } = await supabase
         .schema('connect')
         .from('threads')
         .update(updates)
         .eq('id', req.params.id)
         .select('id, title, body, author_display_name, reply_count, created_at, last_activity_at, updated_at')
         .single();
       ```
       - The DB trigger `trg_log_thread_edit` fires AFTER UPDATE when `OLD.title IS DISTINCT FROM NEW.title OR OLD.body IS DISTINCT FROM NEW.body` — this happens automatically. If content is unchanged (no-op), trigger does NOT fire and no edit history row is created.
       - If error or !data: return `500`
    7. Cache invalidation:
       ```typescript
       await cacheDel(`fc:/api/threads/${req.params.id}:${JSON.stringify({})}`);
       ```
    8. Return `200` with camelCase response:
       ```typescript
       res.status(200).json({
         data: {
           id: data.id,
           title: data.title,
           body: data.body,
           authorPseudonym: data.author_display_name,
           replyCount: data.reply_count,
           createdAt: data.created_at,
           lastActivityAt: data.last_activity_at,
           updatedAt: data.updated_at,
           isEdited: data.updated_at !== data.created_at,
         },
       });
       ```
       - `isEdited` derived from timestamp comparison. For a true no-op where content is identical, `updated_at` is still explicitly set in the update payload, so `isEdited` will be `true`. This is correct — the user submitted an edit action.

    IMPORTANT: PATCH does NOT use the rate limiter. Editing is unlimited per CONTEXT.md decision.

    **GET /api/threads/:id/edits** — Add to `src/routes/threads.ts`:

    1. Add route: `threadsRouter.get('/threads/:id/edits', async (req, res) => { ... })`
       - NO auth required — edit history is public (Memory over Moderation principle)
       - NO cache middleware — edit history is low-traffic and should always be fresh
    2. Verify thread exists and is visible:
       ```typescript
       const { data: thread, error: threadError } = await supabase
         .schema('connect')
         .from('threads')
         .select('id, moderation_status')
         .eq('id', req.params.id)
         .single();
       ```
       - If not found or hidden: return `404` with `{ error: { code: 'THREAD_NOT_FOUND', message: 'Thread not found' } }`
    3. Fetch edit history:
       ```typescript
       const { data, error } = await supabase
         .schema('connect')
         .from('thread_edits')
         .select('id, old_title, old_body, edited_at')
         .eq('thread_id', req.params.id)
         .order('edited_at', { ascending: false });
       ```
       - If error: return `500`
    4. Return `200` with camelCase response:
       ```typescript
       res.json({
         data: (data ?? []).map(e => ({
           id: e.id,
           oldTitle: e.old_title,
           oldBody: e.old_body,
           editedAt: e.edited_at,
         })),
       });
       ```
       - Returns empty array if no edits exist (thread was never edited)
