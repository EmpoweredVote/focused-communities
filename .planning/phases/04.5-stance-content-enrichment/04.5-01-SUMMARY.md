## Decisions Recorded

- `description` is nullable TEXT (not NOT NULL) — shared inform schema may have rows from other products without authored content; enforce non-null via seed, not schema constraint
- `example_perspectives` is TEXT[] NOT NULL DEFAULT '{}' — empty array is safe default for unauthored rows
- RPC required DROP + CREATE (not CREATE OR REPLACE) because PostgreSQL cannot change RETURNS TABLE column list in place
- Executed in orchestrator (not subagent) due to 32k output token limit hit during subagent attempt — content volume for 160 stances exceeds single-response budget
