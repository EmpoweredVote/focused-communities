    2. Create src/app.ts:
       - Export `createApp()` function (factory pattern -- NO .listen() call)

    3. Create src/server.ts:

       - Import createApp from ./app

    4. Create src/lib/supabase.ts:
       - Export a Supabase client singleton created with createClient()
       - Read SUPABASE_URL and SUPABASE_SERVICE_ROLE_KEY from process.env
       - Throw a clear error if either env var is missing (fail fast, not silent null)

    5. Create src/lib/redis.ts (from Research Pattern 10):
       - Import Redis from '@upstash/redis'
       - Create in-memory fallback: `Map<string, { value: unknown; expiresAt: number }>`
       - Try to initialize Redis.fromEnv(), catch and warn if env vars missing
       - Export `cacheGet<T>(key: string): Promise<T | null>` -- tries Redis first, falls back to Map, checks TTL expiry
       - Export `cacheSet(key: string, value: unknown, ttlSeconds: number): Promise<void>` -- tries Redis first, falls back to Map with expiresAt calculation
       - Both functions must silently fall through to memory on any Redis error (no thrown exceptions)
